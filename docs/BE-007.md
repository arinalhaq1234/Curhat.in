# BE-007 — Google Login backend mobile

## Kontrak

POST `/api/auth/google/`, Content-Type `application/json`:
`{"id_token":"<Google ID token>"}`. Tidak memerlukan Bearer token.
Field email/nama/user_id/privilege dari body tidak digunakan.

Respons 200 mengikuti BE-003:

```json
{
  "success": true,
  "message": "Login berhasil.",
  "data": {
    "access": "<JWT akses Curhat.in>",
    "refresh": "<JWT refresh Curhat.in>",
    "user": {"id": 1, "username": "google_<acak>", "email": "<email terverifikasi>", "is_staff": false}
  }
}
```

SimpleJWT memakai konfigurasi masa berlaku dan blacklist BE-003 yang sama.
Tidak ada endpoint refresh baru. Error berbentuk
`{"success":false,"message":"<pesan Bahasa Indonesia>"}` tanpa detail exception/token.

| Status | Kondisi |
| --- | --- |
| 400 | ID token hilang, tipe salah, terlalu panjang |
| 401 | Token rusak, tanda tangan/issuer/audience salah, kedaluwarsa, identitas/email tidak valid |
| 403 | Akun terhubung nonaktif, staff, atau superuser |
| 409 | Konflik identitas/email; tidak menautkan otomatis |
| 503 | Konfigurasi kosong, verifikasi Google atau database tidak tersedia |

## Environment dan database

Isi `GOOGLE_CLIENT_ID` melalui environment backend atau `backend/.env` yang diabaikan
Git. Nilainya harus sama dengan audience ID token mobile. Jika mobile menggunakan
server/web client ID untuk native Google Sign-In, gunakan ID tersebut di backend.
Audience tidak diambil dari body request. Tidak perlu client secret.
`google-auth` dan `requests` sudah tersedia dalam requirements.

Dari direktori backend, setelah konfigurasi database deployment siap:

```powershell
.\.venv\Scripts\python.exe manage.py migrate
```

Migrasi 0006 hanya menambah GoogleIdentity (subject unik, email normalisasi unik,
relasi satu-ke-satu ke User). Tidak mengubah RiwayatCurhat atau akun lama.
Migrasi database deployment belum dijalankan; pengujian hanya memakai SQLite sementara.

## Identitas dan keamanan akun

- Verifikasi memakai `google.oauth2.id_token.verify_oauth2_token`.
- Identitas berdasarkan `sub`, bukan email. Email wajib terverifikasi.
- Email yang sudah dipakai User diperiksa case-insensitive dan ditolak tanpa penautan.
- User baru: password unusable, is_staff=false, is_superuser=false.
- Jika email Google berubah, identitas tetap memakai user yang sama berdasarkan sub;
  email akun tidak diperbarui otomatis.
- Pembuatan user/identitas atomik; konflik constraint membatalkan user baru.
- Tidak ada perubahan login password, admin web, mobile, Gemini, atau endpoint curhat.

Catatan di luar cakupan: email User bawaan Django tidak unik pada database dan
registrasi password lama tidak memberlakukan keunikan email. BE-007 tidak mengubah
kebijakan tersebut. Pemeriksaan email BE-007 bukan jaminan keunikan email global
terhadap registrasi password bersamaan; tidak ada penautan otomatis sehingga
duplikasi email tidak memberikan akses ke akun lain.

## Integrasi mobile

1. Dapatkan Google ID token dengan audience yang sesuai GOOGLE_CLIENT_ID backend.
2. Kirim id_token melalui HTTPS ke endpoint di atas (bukan Google access token).
3. Pada 200, simpan data.access dan data.refresh dengan mekanisme BE-003.
4. Gunakan JWT akses Curhat.in untuk profil/curhat; bukan ID token Google.
5. Pada error tampilkan message tanpa membuat sesi; pada 409 gunakan metode login lama.

## Pengujian

```powershell
.\.venv\Scripts\python.exe manage.py check --settings=backend_curhat.test_settings
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run --settings=backend_curhat.test_settings
.\.venv\Scripts\python.exe manage.py test api.test_google_login --settings=backend_curhat.test_settings
.\.venv\Scripts\python.exe manage.py test api --settings=backend_curhat.test_settings
```

10 tes BE-007 lulus. JWT RSA ditandatangani dengan kunci uji; hanya pengambilan
sertifikat dimock, bukan validasi tanda tangan, issuer, expiry, atau audience.
Pemeriksaan Django dan kecocokan migrasi lulus.
Suite lengkap: 91 tes, 22 kegagalan tes/subtes audio lama yang memakai WAV,
sementara endpoint saat ini menerima M4A/AAC. Kode audio tidak diubah untuk BE-007.
Uji live Google dan integrasi perangkat mobile belum dilakukan.
