# 💬 Curhat.in

> Ruang digital berbasis AI untuk membantu mahasiswa bercerita dan memahami kondisi emosionalnya melalui teks maupun suara.

---

## 🌱 Tentang Curhat.in

Curhat.in adalah aplikasi mobile berbasis Artificial Intelligence (AI) yang dirancang sebagai ruang bagi mahasiswa untuk menyampaikan cerita dan kondisi emosional melalui teks maupun rekaman suara.

Sistem menggunakan Google Gemini API untuk memahami konteks curhatan, mengidentifikasi kategori emosi, membuat ringkasan cerita, memberikan respons empatik, serta menghasilkan rekomendasi positif sebagai bantuan awal bagi pengguna.
